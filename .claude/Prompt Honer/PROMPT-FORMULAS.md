# Prompt Formulas

12 templates for different website types. Fill in the brackets. Paste into Stitch (or v0, Lovable, Bolt).

---

## The Master Formula

Every good design prompt has these 6 parts:

```
[1. Mood/adjectives] + [2. What it is] + [3. Brand name + context]
+ [4. Who it's for] + [5. Specific sections/screens]
+ [6. Design details: colors, fonts, references]
```

**Example built from formula:**
```
A warm and editorial product page for a premium ceramics brand called
"Kilnwork" selling handmade bowls to design-conscious homeowners aged 28-45.

Include a full-width hero image, product name with price ($68), color
selector with 3 glaze options, "Add to Cart" button, material details,
and a "You might also like" grid of 4 items.

Style: Cream background (#f5f0eb), dark warm text (#2d2926), sage green
accent (#6b7c5e). Serif headings, sans-serif body. Photography-first.
Think Aesop meets East Fork Pottery.
```

## Formula 1: SaaS Landing Page

```
A [mood] landing page for a [type of tool] called "[Brand Name]" that
helps [target audience] [solve what problem].

Sections: hero with [headline style] and [CTA type], social proof strip
with [number] logos, feature grid with [number] cards, [pricing/testimonials/FAQ],
and footer.

Style: [background color], [text color], [accent color]. [Font style].
[Whitespace level]. Inspired by [reference product].
```

```

selling [specific product] at [price point] to [target buyer].

Layout: [hero image size], product name, price, [variant selector type],

Style: [background], [text], [accent]. [Heading font style], [body font style].
```

## Follow-Up Prompt Templates

After your initial prompt, iterate with these one-at-a-time:

### Layout Changes
- `Move the [section] above the [other section]`
- `Make the hero full-width with the image as background and text overlay`
- `Switch the features section to a 2-column layout instead of 3`
- `Add a sticky navigation bar that appears on scroll`

### Style Changes
- `Change the primary color to [hex code]`
- `Use a serif font for headings and keep sans-serif for body`
- `Make all buttons fully rounded with pill shape`
- `Add more whitespace between sections, currently feels too tight`
- `Darken the background to [hex] and make text lighter`

### Component Additions
- `Add a testimonial carousel between the features and pricing sections`
- `Add a "How It Works" section with 3 numbered steps`
- `Add a floating chat button in the bottom right`
- `Add breadcrumb navigation at the top of the product page`

### Content Refinements
- `Change the hero headline to "[your headline]"`
- `Add a subtitle under the headline: "[your subtitle]"`
- `Replace the placeholder logos with text that says [Company 1], [Company 2], etc.`

### Mobile
- `Create a mobile version of this page`
- `On mobile, stack the 3-column grid into a single column`
- `Replace the top nav with a hamburger menu on mobile`

### Prototyping
- `Connect all screens. The [element] on [screen 1] should link to [screen 2]`
- `Add a loading skeleton screen that shows before the dashboard loads`
- `Create an empty state for when no [items] exist yet`
